# MiniNAS v0.8 릴리즈 노트 (Release Notes)

> 버전: v0.8  
> 릴리즈 일자: 2026년 11월 18일  
> 대상 플랫폼: 2011 Mac mini (Intel Core i5, macOS High Sierra 10.13+) 및 최신 모바일/웹 브라우저

---

## 1. 개요

MiniNAS v0.8은 미디어 허브 전용 폴더 격리 스캔, 포토 & 모먼트 앨범(폴더) 단위 보기, EXIF(JPEG/HEIC) 및 MP4/MOV 메타데이터 기반 실제 촬영일 자동 분류, EXIF 회전 보정 경량 썸네일 캐싱, 미디어 뷰어 상세 메타 정보 표시를 포함한 주요 업데이트입니다.

---

## 2. 주요 변경 사항

### 2.1 미디어 허브 전용 폴더 격리 스캔
- 일반 작업 폴더나 백업 폴더에 업로드한 사진·영상이 미디어 허브에 무분별하게 섞이지 않도록 각 허브가 약속된 전용 폴더만 탐색합니다.
- 시네마 허브: `movies`, `cinema` 저장소 및 각 저장소 최상위의 `영화`, `드라마`, `시네마`, `애니`, `애니메이션`, `예능`, `방송`, `cinema`, `movies`, `movie`, `dramas`, `drama`, `series`, `vod`, `tv`, `ani`, `anime` 폴더만 스캔합니다.
- 포토 & 모먼트: `photos`, `albums` 저장소 및 각 저장소 최상위의 `사진`, `앨범`, `포토`, `카메라`, `일상`, `가족`, `여행`, `추억`, `photos`, `photo`, `albums`, `album`, `pictures`, `picture`, `dcim`, `camera`, `moments`, `moment` 폴더만 스캔합니다.
- 음악 허브: `music` 저장소 및 각 저장소 최상위의 `음악`, `노래`, `오디오`, `music`, `musics`, `audio`, `songs`, `song`, `ost`, `playlist`, `playlists` 폴더만 스캔합니다.

### 2.2 포토 & 모먼트 앨범(폴더) 단위 보기 및 UI 개선
- 기본 화면으로 하위 폴더 단위의 앨범 카드 보기를 제공합니다.
- 각 앨범 카드에 대표 표지 썸네일, 앨범명, 사진·영상 개수, 촬영 시기 범위, 총 용량을 표시하여 초기 진입 시 수천 장의 이미지를 한꺼번에 렌더링하는 부하를 제거했습니다.
- 상단 스위치로 `앨범` 보기와 전체 `타임라인` 보기를 즉시 전환할 수 있습니다.
- 타일 하단의 호버 정보를 단일 캡션 바로 통합하여 촬영일과 앨범명이 겹치는 문제를 해결했습니다.

### 2.3 메타데이터 기반 실제 촬영일 추출 및 정밀 분류
- 업로드 시각(`ModTime`) 대신 파일 내부 메타데이터를 파싱하여 실제 촬영일(`TakenAt`) 기준으로 정렬합니다.
- JPEG 및 HEIC/HEIF 파일의 EXIF(`DateTimeOriginal`, `DateTimeDigitized`) 태그를 직접 파싱합니다.
- MP4 및 MOV 동영상의 `mdat` 구간을 `Seek`로 건너뛰어 파일 끝에 위치한 `moov/mvhd` 생성 시각과 QuickTime ISO-8601 생성 시각을 고속 추출합니다.
- 내부 생성 시각이 비어 있는 아이폰 라이브 포토(`.mov`) 및 파생 이미지는 동일 폴더 내 짝꿍 원본 사진(`IMG_XXXX`)의 촬영일을 자동으로 상속합니다.
- 메신저 전송 등으로 메타데이터가 지워진 파일은 파일명·폴더 경로 날짜 패턴 또는 동일 앨범 내 인접 파일의 촬영일을 이어받아 분류합니다.
- 웹 업로드 시 클라이언트의 원본 `lastModified` 시각을 서버 파일 시스템에 보존합니다.

### 2.4 경량 썸네일 캐시, 회전 보정, 고아 캐시 자동 정리
- 사진 바둑판 및 파일 탐색기 그리드 뷰에서 수 MB 원본 대신 `/api/photos/thumb` 경량 썸네일을 서빙합니다.
- EXIF 내장 썸네일 추출 시 원본 사진의 `Orientation`(`0x0112`) 회전 헤더를 함께 주입하여 세로 사진이 가로로 눕는 현상을 해결하고, `object-contain`으로 원본 종횡비를 보존합니다.
- 동영상 썸네일도 최초 1회 캡처 후 서버 `.mininas_cache/thumbs/`에 영구 저장(`POST /api/photos/thumb`)하여 재접속 시 비디오 디코딩 없이 즉시 이미지로 표시합니다.
- 원본 파일이 삭제되거나 이동되면 `.mininas_cache/media_index_v2.json` 항목과 `.mininas_cache/thumbs/` 내 고아 썸네일 파일을 자동으로 삭제합니다.

### 2.5 상세 메타 정보 확인 (`파일 및 메타 정보` 모달 & 미디어 뷰어)
- `/api/media/meta` 엔드포인트를 추가하여 촬영일시(출처 배지 포함), 해상도(회전 반영), 카메라 제조사·모델명, 조리개(`fNumber`), 노출 시간, ISO, 동영상 재생 시간, GPS 위치 포함 여부를 제공합니다.
- 파일 탐색기 상세 정보 모달, 포토 허브 타일 우측 상단 `i` 버튼(및 우클릭), 전체 화면 미디어 뷰어 상단 `정보` 버튼(단축키 `I`)에서 언제든 메타 정보를 확인할 수 있습니다.
