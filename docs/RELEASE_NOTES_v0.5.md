# MiniNAS v0.5 릴리즈 노트 (Release Notes)

> **버전**: v0.5.0  
> **릴리즈 일자**: 2026년 11월 16일  
> **대상 플랫폼**: 2011 Mac mini (macOS High Sierra 10.13+) 및 최신 macOS  
> **아키텍처**: Pure Go (CGO=0) + React/TypeScript 단일 내장 바이너리

---

## 릴리즈 개요

MiniNAS v0.5는 원본 화질을 유지하면서 네트워크 상태에 따른 동영상 버퍼링을 개선한 미디어 스트리밍 최적화 릴리즈입니다.

브라우저의 소극적 기본 버퍼 정책과 고비트레이트 직송출 환경에서 발생하는 버퍼 채터링(0.5초마다 멈추는 반복 현상)을 원천 차단합니다. 실시간 버퍼 모니터링 HUD와 무손실 FastStart 헤더 최적화를 결합하여 외부 모바일 접속과 Wi-Fi 음영 지역에서도 쾌적한 시청 환경을 제공합니다.

---

## 주요 변경 사항

### 1. 프론트엔드 스마트 버퍼링 & 안티 채터링 (Anti-Chattering)
* **적극적 선행 다운로드 (`preload="auto"`)**:
  * 브라우저가 유휴 네트워크 상태에서 소극적으로 멈추지 않고 선행 데이터를 적극적으로 다운로드합니다.
* **안티 채터링(Anti-Chattering) 안전 버퍼 회복**:
  * 네트워크가 지연될 때(`waiting`, `stalled`), 0.5초 만에 불완전하게 재생을 재개하지 않습니다.
  * 최소 4초 분량의 안전 버퍼를 확보할 때까지 대기한 후 자동으로 부드럽게 재생을 재개합니다.
* **반투명 충전 HUD 오버레이**:
  * 버퍼 고갈 시 화면 중앙에 현재 충전 상태(`현재 X.Xs / 목표 4.0s`)를 시각화합니다.
* **실시간 스트리밍 버퍼 HUD 상태 바**:
  * 비디오 플레이어 하단에 현재 확보된 버퍼 초수(예: `34.2초 확보됨`) 및 상태 배지(매우 쾌적 / 안전 / 버퍼 부족)를 실시간 표시합니다.
  * 전체 영상 길이 대비 다운로드 완료 구간 비율(%)을 표시합니다.

### 2. 백엔드 무손실 FastStart 웹 최적화 (`media_converter.go`)
* **100% 무손실 FastStart 헤더 이동 (`-c copy -movflags +faststart`)**:
  * 비디오와 오디오를 재인코딩하지 않고 파일 메타데이터(`moov atom`)를 파일 선두로 이동합니다.
  * 대용량 고화질 MP4 파일의 첫 프레임 재생 시작 지연(TTFF)을 4~6배 단축(0.3~0.6초대)합니다.
  * 원거리 탐색(Seek) 시 바이트 오프셋을 즉각 계산하여 딜레이 없는 탐색을 지원합니다.
* **웹 변환 모달 옵션 연동**:
  * '웹 호환 고속 변환' 모달에 `무손실 스트리밍 최적화 (FastStart)` 옵션을 추가했습니다.
  * 오디오 변환 시에도 항상 FastStart를 기본 적용합니다.
