# MiniNAS v0.5 릴리즈 노트 (Release Notes)

> **버전**: v0.5.0  
> **릴리즈 일자**: 2026년 11월 16일  
> **대상 플랫폼**: 2011 Mac mini (macOS High Sierra 10.13+) 및 최신 macOS  
> **아키텍처**: Pure Go (CGO=0) + React/TypeScript 단일 내장 바이너리

---

## 📌 릴리즈 개요

MiniNAS v0.5는 **"화질을 1픽셀도 낮추지 않고(100% 원본 유지), 네트워크 상태에 따른 동영상 끊김(버퍼링) 현상을 개선"**한 미디어 스트리밍 최적화 업데이트입니다.

브라우저의 소극적인 기본 버퍼 정책과 고비트레이트 직송출 환경에서 발생하는 **버퍼 채터링(0.5초마다 멈추는 반복 현상)**을 근본적으로 차단하고, 실시간 버퍼 모니터링 HUD와 무손실 FastStart 헤더 최적화를 결합하여 외부 모바일 접속이나 Wi-Fi 음영 지역에서도 쾌적하고 끊김 없는 시청 경험을 제공합니다.

---

## 🌟 주요 변경 사항 (What's New)

### 1. 프론트엔드 스마트 버퍼링 & 안티 채터링 (Anti-Chattering)
* **적극적 선행 다운로드 (`preload="auto"`)**:
  * 브라우저가 유휴 네트워크 상태에서 소극적으로 멈추지 않고 적극적으로 선행 데이터를 다운로드하도록 개선.
* **안티 채터링(Anti-Chattering) 안전 버퍼 회복**:
  * 네트워크가 순간적으로 느려졌을 때(`waiting`/`stalled`), 0.5초 만에 어설프게 틀었다가 다시 멈추는 악순환을 원천 차단.
  * **최소 4초 분량의 안전 버퍼가 확보될 때까지 대기 후 자동으로 부드럽게 재생을 재개**합니다.
* **반투명 충전 HUD 오버레이**:
  * 버퍼 고갈 시 화면 중앙에 세련된 애니메이션과 함께 현재 충전 상태(`현재 X.Xs / 목표 4.0s`)를 직관적으로 시각화.
* **실시간 스트리밍 버퍼 HUD 상태 바**:
  * 비디오 플레이어 하단에 현재 확보된 버퍼 초수(예: `34.2초 확보됨`) 및 상태 뱃지(🟢 매우 쾌적 / 🟡 안전 / 🔴 버퍼 부족)를 실시간 렌더링.
  * 전체 영상 길이 대비 다운로드 완료된 구간 비율(%) 표시.
* **[⚡ 10초 안전 버퍼 충전] 원클릭 부스터**:
  * 외부 LTE나 신호가 불안정한 Wi-Fi 환경에서 원클릭으로 10초 분량의 버퍼를 미리 채운 뒤 연속 감상할 수 있는 수동 부스터 지원.

### 2. 백엔드 무손실 FastStart 웹 최적화 (`media_converter.go`)
* **100% 무손실 FastStart 헤더 이동 (`-c copy -movflags +faststart`)**:
  * 비디오/오디오 재인코딩(화질 손상) 없이 파일의 인덱스 메타데이터(`moov atom`)를 파일 맨 앞으로 이동.
  * 대용량 고화질 MP4 파일의 첫 프레임 재생 시작 지연(TTFF)을 **4~6배 단축(0.3~0.6초대)**.
  * 영상 중간이나 끝부분으로 원거리 탐색(Seek) 시 바이트 오프셋을 즉각 계산하여 딜레이 없는 탐색 지원.
* **웹 변환 모달 옵션 연동**:
  * '웹 호환 고속 변환' 모달에 `무손실 스트리밍 최적화 (FastStart)` 옵션 추가.
  * 오디오 변환 시에도 항상 FastStart가 기본 적용되어 웹 스트리밍에 최적화됨.
