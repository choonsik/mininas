# MiniNAS v0.7 릴리즈 노트 (Release Notes)

> **버전**: v0.7  
> **릴리즈 일자**: 2026년 11월 17일  
> **대상 플랫폼**: 2011 Mac mini (Intel Core i5, macOS High Sierra 10.13+) 및 최신 모바일/웹 브라우저

---

## 1. 개요

MiniNAS v0.7은 모바일 사용자 경험(UX) 전면 개선, 음원 내장 앨범 표지(ID3v2 Cover Art) 고속 추출, 외형 및 시스템 제어의 좌측 사이드바 일원화, 파일 탐색기 조작성 강화를 포함한 주요 업데이트입니다.

---

## 2. 주요 변경 사항

### 2.1 모바일 사용자 경험(UX) 및 미디어 뷰어 최적화
- **하단 반투명 캡슐 컨트롤러 적용**:
  - 화면 중앙 좌우에 떠 있던 이전/다음 플로팅 버튼을 모바일 화면에서는 하단 중앙 캡슐로 이동했습니다.
  - 컨텐츠 가림 현상을 완전히 해소했습니다.
- **내비게이션 지터(Jitter) 방지**:
  - 고정폭 숫자 속성(`tabular-nums`) 및 최소 너비(`min-w-[4.8rem]`)를 지정했습니다.
  - 파일 인덱스 변경 시 버튼 위치 흔들림과 줄바꿈을 차단했습니다.
- **모바일 불필요 정보 숨김**:
  - 터치 환경에서 불필요한 키보드 단축키 안내 및 전체 파일 경로 하단 바를 모바일에서 제거했습니다.
- **부드러운 스크롤 및 세이프 에어리어 대응**:
  - 사이드바 `justify-between` 레이아웃을 단일 수직 플로우(`overflow-y-auto`)로 개편했습니다.
  - 화면 높이가 좁은 모바일 기기에서도 외형 설정과 시스템 푸터가 겹치지 않고 자연스럽게 스크롤됩니다.
  - 모바일 하단 홈 바 영역 침범을 방지하는 세이프 에어리어 패딩을 적용했습니다.

### 2.2 음악 앨범 표지(Cover Art) 지원
- **ID3v2 태그 파서 내장**:
  - Go 표준 라이브러리만을 사용하여 MP3(ID3v2.2, ID3v2.3, ID3v2.4) APIC/PIC 프레임 및 FLAC PICTURE 블록을 직접 파싱합니다.
  - 고유 엔드포인트(`/api/music/cover`)를 통해 JPEG/PNG 바이너리를 즉시 추출합니다.
- **폴더 커버 이미지 대체(Fallback)**:
  - 파일 내 태그가 없으면 디렉토리 내 `cover.jpg`, `folder.jpg`, `album.jpg` 등을 자동으로 탐색하여 서빙합니다.
- **인메모리 및 HTTP 캐싱**:
  - 파일 수정 시각 기반의 메모리 캐시 및 브라우저 장기 캐시(`max-age=86400`)를 적용했습니다.
- **UI 앨범 표지 표시**:
  - 앨범 카드 그리드 뷰, 음원 목록 행, 글로벌 백그라운드 오디오 플레이어에 커버 아트를 연동했습니다.
  - 표지가 없을 때는 디스크 아이콘으로 안전하게 전환합니다.

### 2.3 외형 설정 및 시스템 모니터링 일원화
- **좌측 사이드바 외형 및 스타일 통합**:
  - 테마 스타일 (macOS / Console / Studio) 3단계 원클릭 세그먼트 버튼 제공.
  - 컬러 톤 (다크 / 나이트 / 라이트) 3단계 원클릭 세그먼트 버튼 제공.
  - 텍스트 크기 (작게 / 보통 / 크게) 3단계 원클릭 세그먼트 버튼 제공.
  - 모바일과 데스크톱 모두 사이드바 단일 지점에서 모든 외형을 제어합니다.
- **좌측 사이드바 시스템 정보 푸터 확장**:
  - 호스트명, CPU 실시간 부하율(%) 및 컬러 슬림 게이지, 메모리 사용률(%) 및 게이지, 연속 가동 시간을 일목요연하게 표시합니다.
- **상단 헤더 순수화**:
  - 중복되던 테마 드롭다운, 폰트 크기 드롭다운, 시스템 정보 칩을 헤더에서 완전히 제거했습니다.
  - 상단 헤더를 검색 및 파일 뷰/정렬 전용 툴바로 정돈했습니다.

### 2.4 탐색기 선택 조작 버그 수정 및 기능 강화
- **전체 선택 체크박스 토글 버그 해결**:
  - 전체 선택 상태에서 체크박스 클릭 시 전체 취소(`onClearSelection`)가 정상 실행되도록 수정했습니다.
- **부분 선택(Indeterminate) 아이콘 적용**:
  - 파일 중 일부만 선택된 경우 마이너스 사각 아이콘(`<MinusSquare />`)을 표시합니다.
- **단축키 연동**:
  - 파일 탐색 화면에서 `Cmd + A` / `Ctrl + A` 단축키 입력 시 전체 선택 및 전체 취소가 상호 토글됩니다.
