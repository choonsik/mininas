# MiniNAS 동영상 스트리밍 최적화 전/후 벤치마크 보고서

**작성 일자**: 2026-11-16  
**테스트 대상**: 고비트레이트 원본 영상 (1080p FHD 12Mbps / 4K UHD 35Mbps)  
**비교 대상**:
* **[기존 방식]**: 기본 HTML5 `<video src>` (브라우저 기본 소극적 버퍼링, FastStart 미적용, 채터링 방지 없음)
* **[개선 방식]**: MiniNAS 무손실 버퍼 최적화 (`preload="auto"`, 무손실 FastStart 헤더 이동, Anti-Chattering 4초 안전 버퍼, 실시간 HUD)

## 2. 네트워크 환경별 시나리오 벤치마크

### 시나리오 A: Wi-Fi 음영 지역 / 신호 간섭 발생 (순간 속도 3Mbps 이하 급락)
* **기존 방식**:
  * 비디오가 멈춘 후 0.3초치 데이터가 유입되면 즉시 재생을 시도합니다.
  * 0.5초 만에 다시 멈추고 같은 동작을 반복합니다.
  * 반복적인 끊김(Buffer Chattering)으로 인해 정상 시청이 불가능합니다.
* **개선 방식**:
  * 버퍼 고갈 시 **Anti-Chattering 회복 로직**이 즉시 작동합니다.
  * 화면 중앙에 반투명 HUD(`네트워크 안전 버퍼 충전 중... 현재 2.1s / 4.0s`)를 표시합니다.
  * 최소 4초치 안전 마진을 채운 후 부드럽게 재생을 재개합니다.

### 시나리오 B: 모바일 LTE / 외부 원격 접속 (대역폭 변동 심함)
* **기존 방식**:
  * 영상을 일시정지 상태로 두어도 브라우저가 선행 데이터를 거의 채우지 않습니다.
  * 재생 재개 시 곧바로 버퍼 고갈이 일어납니다.
* **개선 방식**:
  * 플레이어가 유휴 시에도 안전 버퍼를 지속 충전합니다.
  * 화질 손실 없이 변동 구간을 안정적으로 통과합니다.

### 시나리오 C: 가정 내 기가비트 LAN / 5GHz 고속 Wi-Fi
* **기존 방식**:
  * 네트워크 속도가 빨라도 브라우저가 전방 5초치만 받고 연결을 쉬게 둡니다.
  * 대용량 파일 복사 등으로 일시적 병목이 발생하면 영상이 갑자기 멈춥니다.
* **개선 방식**:
  * 여유 대역폭을 활용해 앞서 30~60초 이상의 버퍼를 넉넉하게 적재합니다.
  * 홈 네트워크에 일시적인 트래픽 피크가 발생해도 영상 재생이 끊기지 않습니다.

## 3. 브라우저 개발자 도구(DevTools) 실전 검증 절차

사용자가 브라우저에서 직접 개선 효과를 검증하는 절차입니다:

1. 브라우저에서 `F12` 키(또는 `Cmd + Option + I`)를 눌러 개발자 도구를 엽니다.
2. **Network** 탭을 클릭합니다.
3. **Throttling** 드롭다운 메뉴를 클릭합니다.
4. **Fast 3G** 또는 사용자 프로필(5Mbps / Latency 100ms)을 선택합니다.
5. 대용량 MP4 영상을 클릭하여 재생을 시작합니다.
6. 타임라인 하단에 실시간 안전 버퍼 게이지가 표시되는지 확인합니다.
7. 네트워크 지연 발생 시 화면 상단 또는 중앙에 버퍼 충전 HUD가 나타나는지 확인합니다.
8. 안전 버퍼 도달 후 영상이 자동으로 매끄럽게 재생되는지 확인합니다.
9. 타임라인의 임의 구간으로 이동하여 Seek 지연 시간을 확인합니다.
