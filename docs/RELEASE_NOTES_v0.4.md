# MiniNAS v0.4 릴리즈 노트 (Release Notes)

> **버전**: v0.4  
> **릴리즈 일자**: 2026년 11월 16일  
> **대상 플랫폼**: 2011 Mac mini (macOS High Sierra 10.13+) 및 최신 macOS  
> **아키텍처**: Pure Go (CGO=0) + React/TypeScript 단일 내장 바이너리

---

## 릴리즈 개요

MiniNAS v0.4는 기존 파일 탐색기와 미디어 감상 기능이 혼재되어 발생하던 UX 마찰을 해소하고, [파일 탐색기]와 [3대 미디어 & 공유 허브]의 역할을 명확히 분리한 메이저 업데이트입니다.

미디어는 전용 허브에서 무제한으로 감상하고, 탐색기는 폴더 계층 관리와 뷰 모드 전환에 집중하도록 개선했습니다.

---

## 주요 변경 사항

### 1. 역할의 명확한 분리 (Role Separation)
* **파일 탐색기 본연의 임무 복원**:
  * 상단 헤더의 `[전체 | 사진 | 영상]` 버튼 그룹을 제거했습니다.
  * 검색창은 현재 폴더 내 빠른 필터링 및 검색을 담당합니다.
  * 불필요한 웹호스팅 열기 바로가기와 레거시 넷플릭스 뷰를 제거하여 프론트엔드 번들을 경량화했습니다.
* **격자(`Grid`) ↔ 목록(`List`) 뷰의 독립적 상호작용**:
  * 뷰 모드 분기가 미디어 필터와 충돌하던 현상을 수정했습니다.
  * 우측 상단 `[격자 보기]`와 `[목록 보기]` 클릭 시 지연 없이 즉각 전환합니다.

### 2. 포토 & 모먼트 (Photos Hub) 혁신
* **인위적인 폴더 및 용량 제한 전면 철폐**:
  * 기존 5,000개 수집 한도를 삭제했습니다. 1만 장 이상의 대용량 사진 앨범도 디스크 끝까지 누락 없이 수집합니다.
  * 기존 150MB 동영상 용량 제한을 삭제했습니다. 스마트폰 4K 영상과 홈 비디오도 타임라인에 모두 표시합니다.
  * 기존 폴더 깊이(depth > 4) 제한을 삭제했습니다. 깊은 하위 폴더의 미디어도 빠짐없이 검색합니다.
* **스마트 스킵 폴더 토글 탑재**:
  * 상단 툴바에 `[시네마/웹 제외] ↔ [모든 폴더 포함]` 토글 버튼을 제공합니다.
  * **기본 모드 (`시네마/웹 제외`)**: `movies`, `dramas`, `sites` 폴더를 제외하여 순수 개인 일상 사진과 비디오만 표시합니다.
  * **전체 모드 (`모든 폴더 포함`)**: 원클릭으로 외장 HDD의 드라마와 영화 폴더까지 전부 포함하여 조망합니다.
* **원본 종횡비(Aspect Ratio) 보존 썸네일 엔진**:
  * 강제 480x270 스케일링을 폐지하고 캔버스 캡처 기반 원본 가로/세로 비율 보존(`object-contain`)을 적용했습니다.
  * 세로 영상(9:16)과 4:3 클래식 영상도 왜곡이나 크롭 없이 원본 비율로 표시합니다.

### 3. 웹 사이트 쇼케이스 (Sites Hub) 고도화
* **16:9 반응형 썸네일 확대**:
  * 화면 폭이 넓어질 때 카드 썸네일도 반응형으로 커지도록 `ResizeObserver` 스케일링을 적용(`2xl:grid-cols-4` 지원)했습니다.
* **사이트 탐지 기준 정립**:
  * `index.html`이 있는 완성된 웹 프로젝트를 자동 감지합니다.
  * 개별 아카이브 HTML은 탐색기 우클릭 `[사이트 허브에 고정]`으로 손쉽게 핀 등록하고 관리합니다.

### 4. 시네마 허브 (Cinema Hub)
* 수량 제한(500개)을 해제하고 외장 HDD `dramas`, `movies` 폴더를 자동 스캔합니다.
* 한국어 자막(SRT, SMI, VTT)을 자동 매칭하고 실시간 UTF-8 변환 스트리밍을 제공합니다.

### 5. 배포 신뢰성 & 브라우저 캐시 방지
* **SMB 네트워크 공유 원자적 교체 (`Atomic Rename`)**:
  * macOS SMB 공유 상에서 실행 중인 바이너리 덮어쓰기 오류를 방지하기 위해 `mininas.new -> mv -f` 원자적 교체 방식을 적용했습니다.
* **SPA no-cache 헤더 적용**:
  * `index.html`에 `Cache-Control: no-cache, no-store, must-revalidate`를 강제하여 브라우저 새로고침만으로 최신 코드를 즉시 반영합니다.

## 아키텍처 비교 (v0.3 -> v0.4)

| 항목 | v0.3 이전 | v0.4 |
| :--- | :--- | :--- |
| **파일 탐색기 상단** | `[전체\|사진\|영상]` 필터로 폴더 트리 혼선 | 순수 디렉토리 탐색 + 빠른 검색창 |
| **격자/목록 전환** | 사진/영상 필터 시 목록 전환 불가 오류 | 독립적 즉시 전환 |
| **포토 허브 수집 한도** | 최대 5,000개 / 150MB 초과 영상 스킵 | 무제한 수집 / 용량 제한 철폐 |
| **스킵 폴더 제어** | 코드 하드코딩으로 무조건 스킵 | 상단 원클릭 토글 (시네마 제외 ↔ 전체 포함) |
| **동영상 썸네일** | 480x270 강제 왜곡 및 크롭 | 원본 종횡비 보존 (세로/가로 100% 정상) |
| **배포 방식** | 단순 `cp` (SMB 파일 잠금 시 실패) | `mininas.new -> mv -f` 원자적 교체 |
| **번들 크기** | 309 KB (미사용 컴포넌트 잔존) | 304 KB (코드 최적화 완료) |
