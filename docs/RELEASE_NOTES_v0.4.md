# MiniNAS v0.4 릴리즈 노트 (Release Notes)

> **버전**: v0.4.0  
> **릴리즈 일자**: 2026년 11월 16일  
> **대상 플랫폼**: 2011 Mac mini (macOS High Sierra 10.13+) 및 최신 macOS  
> **아키텍처**: Pure Go (CGO=0) + React/TypeScript 단일 내장 바이너리

---

## 📌 릴리즈 개요

MiniNAS v0.4는 기존의 파일 탐색기와 미디어 감상 기능이 혼재되어 발생하던 UX 마찰을 해소하고, **[파일 탐색기]와 [3대 미디어 & 공유 허브]의 역할을 완벽하게 분리·정립**한 메이저 업데이트입니다. 

불필요한 중복 기능과 어색한 필터를 걷어내고, 미디어는 전용 허브에서 무제한으로 시원하게 감상하며, 탐색기는 본연의 폴더 계층 관리와 즉각적인 뷰 모드 전환에 집중하도록 완성도를 끌어올렸습니다.

---

## 🌟 주요 변경 사항 (What's New)

### 1. 역할의 명확한 분리 (Role Separation)
* **파일 탐색기 본연의 임무 복원**:
  * 상단 헤더의 어색했던 `[전체 | 사진 | 영상]` 버튼 그룹을 완전히 제거했습니다.
  * 검색창은 이제 순수하게 **현재 폴더 내 빠른 필터링/검색**을 담당하여 디렉토리 계층 감각을 흐트러뜨리지 않습니다.
  * 불필요해진 웹호스팅 열기 바로가기 및 레거시 넷플릭스 뷰를 제거하여 프론트엔드 번들을 슬림화했습니다.
* **격자(`Grid`) ↔ 목록(`List`) 뷰의 완전한 상호작용 독립**:
  * 뷰 모드 분기가 미디어 필터와 충돌하여 전환이 먹히지 않던 버그를 근본적으로 해결했습니다.
  * 우측 상단 `[▦ 격자 보기]`와 `[☰ 목록 보기]` 클릭 시 지체 없이 즉각 전환됩니다.

### 2. 포토 & 모먼트 (Photos Hub) 혁신
* **인위적인 폴더 및 용량 제한 전면 철폐**:
  * 기존의 **5,000개 수집 한도 삭제** ➡️ 1만~5만 장 이상의 대용량 사진 앨범도 디스크 끝까지 누락 없이 100% 수집.
  * 기존의 **150MB 동영상 용량 제한 삭제** ➡️ 폰으로 촬영한 4K 영상, 긴 홈 비디오도 타임라인에 모두 표시.
  * 기존의 **폴더 깊이(depth > 4) 제한 삭제** ➡️ 아무리 깊은 하위 폴더의 미디어도 빠짐없이 발굴.
* **스마트 스킵 폴더 토글 탑재**:
  * 상단 툴바에 **`[시네마/웹 제외]` ↔ `[모든 폴더 포함]`** 토글 버튼 제공.
  * **기본 모드 (`시네마/웹 제외`)**: `movies`, `dramas`, `sites` 등 영화/드라마/웹 에셋을 걸러내고 순수 개인 일상 사진과 비디오만 정갈하게 감상.
  * **전체 모드 (`모든 폴더 포함`)**: 원클릭으로 외장 HDD의 드라마/영화 폴더까지 전부 포함하여 전체 미디어를 한눈에 조망.
* **원본 종횡비(Aspect Ratio) 보존 썸네일 엔진**:
  * 강제 480x270 스케일링을 폐지하고 캔버스 캡처 기반 원본 가로/세로 비율 보존(`object-contain`) 적용.
  * 세로 직캠(9:16), 4:3 클래식 영상 등도 왜곡이나 크롭 없이 완벽하게 프리뷰.

### 3. 웹 사이트 쇼케이스 (Sites Hub) 고도화
* **16:9 반응형 썸네일 확대**:
  * 화면 폭이 넓어질 때 카드 썸네일도 시원하게 반응형으로 커지도록 `ResizeObserver` 스케일링 적용 (`2xl:grid-cols-4` 지원).
* **B+C 기준 정립**:
  * `index.html`이 있는 완성된 웹 프로젝트 자동 감지.
  * 개별 아카이브 HTML은 탐색기 우클릭 **`[📌 사이트 허브에 고정]`**으로 손쉽게 핀 등록 및 관리.

### 4. 시네마 허브 (Cinema Hub)
* 수량 제한(500개) 해제 및 외장 HDD `dramas`, `movies` 폴더 완벽 인식.
* 한국어 자막(SRT, SMI, VTT) 자동 매칭 및 실시간 UTF-8 변환 스트리밍.

### 5. 배포 신뢰성 & 브라우저 캐시 방지
* **SMB 네트워크 공유 원자적 교체 (`Atomic Rename`)**:
  * macOS SMB 공유 상에서 실행 중인 바이너리 덮어쓰기 무시 버그를 극복하기 위해 `mininas.new ➡️ mv -f` 파이프라인 정립.
* **SPA no-cache 헤더 적용**:
  * `index.html`에 `Cache-Control: no-cache, no-store, must-revalidate`를 강제하여 버전 업데이트 시 브라우저 새로고침만으로 즉시 최신 코드 반영.

## 📊 종합 아키텍처 비교 (v0.3 ➡️ v0.4)

| 항목 | v0.3 이전 | v0.4 (현재) |
| :--- | :--- | :--- |
| **파일 탐색기 상단** | `[전체\|사진\|영상]` 필터로 폴더 트리 붕괴 | **순수 디렉토리 탐색 + 빠른 검색창** |
| **격자/목록 전환** | 사진/영상 필터 시 목록 전환 불가 버그 | **100% 독립적 즉시 전환** |
| **포토 허브 수집 한도** | 최대 5,000개 / 150MB 초과 영상 스킵 | **무제한 수집 / 용량 제한 철폐** |
| **스킵 폴더 제어** | 코드 하드코딩으로 무조건 스킵 | **상단 원클릭 토글 (시네마 제외 ↔ 전체 포함)** |
| **동영상 썸네일** | 480x270 강제 왜곡 및 크롭 | **원본 종횡비 보존 (세로/가로 100% 정상)** |
| **배포 방식** | 단순 `cp` (SMB 락 걸릴 시 실패) | **`mininas.new` ➡️ `mv -f` 원자적 교체** |
| **번들 크기** | 309 KB (미사용 컴포넌트 잔존) | **304 KB (코드 다이어트 완료)** |
